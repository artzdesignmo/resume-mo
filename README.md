# Resume Mo

**A résumé studio that updates as you type.** Edit on the left, watch a print-ready A4 résumé update live on the right — no sign-up, no upload, no build step.

Open `index.html` in any browser and start typing. The sample résumé is fictional demo data (Maya Lin, Product Designer) — replace it with your own.

## What it does

- **Live A4 preview** — every keystroke re-renders the résumé instantly
- **6 templates** — Classic, Modern, Minimal (free) + Bold, Creative, Executive (OpenX Pro)
- **8 accent colours**, photo upload (stays on your device), skill dots, language levels
- **Add / reorder / remove** experience, education, skills and languages — up/down buttons included
- **Completeness + word count** live stats; **ATS keyword check** (Pro) shows which hiring keywords your résumé already covers
- **Print / Save as PDF** — print CSS shows only the A4 sheet, ready for A4 paper
- **JSON save / load** — back up a résumé, or move it to another browser
- **EN / 繁中 UI**, white / silver / black themes (OpenX spec, saved in localStorage)
- **Fully offline** — single self-contained HTML file, vanilla JS, zero dependencies except Google Fonts. Nothing is uploaded; your data lives only in this browser's localStorage.

## How to use

1. Open `index.html`.
2. Pick a template and an accent colour.
3. Edit the profile, experience, education, skills and languages on the left.
4. Click **Print / PDF** → Save as PDF for a print-ready A4 file, or **↓ JSON** to back up your data.

## OpenX Pro

Premium templates and the ATS keyword check are unlocked with a shared OpenX Pro key (the same key unlocks Pro across all Mo tools). Click **◆ Pro** in the header and enter your key — it is validated against the OpenX service and stored only on your device.
